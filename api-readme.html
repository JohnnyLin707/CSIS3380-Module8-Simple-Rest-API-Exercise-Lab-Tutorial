Setup — 从零跑通（5 步，已实测成功）

1. 安装依赖

PowerShell（在项目目录）
npm install

2. 填真实 .env（最关键，最容易卡住的一步）

先复制模板，再检查内容：

PowerShell
cp .env.example .env
Get-Content .env

如果还看到 CLUSTER / USER / PASSWORD 占位符，说明是模板，必须替换成真实连接串（从 Atlas → Connect → Drivers → Node.js 复制，mongodb.net/ 后面要有 /UserList）。用下面命令整行覆盖（用单引号，防止 & 被 PowerShell 解释）：

PowerShell — 换成你自己的值
'MONGODB_URI=mongodb+srv://用户名:新密码@cluster1.6qa39ly.mongodb.net/UserList?retryWrites=true&w=majority' | Set-Content .env
'PORT=3000' | Add-Content .env

⚠️ 若忘记这步，npm start 会报 querySrv ENOTFOUND _mongodb._tcp.CLUSTER.mongodb.net——原因就是连接串里还是假的 CLUSTER。另外 # edit .env ... 那行在 PowerShell 里是注释，不会执行，必须手动改。

3. 启动本地服务器

PowerShell
npm start

看到下面两行即成功；浏览器开 http://localhost:3000/api/users 应返回 [] 或用户数组。

期望日志
Connected to MongoDB
UserList API listening on http://localhost:3000

注意：node --watch 不会因为 .env 改动自动重启（只监视被 require 的 JS 文件），改完 .env 要 Ctrl+C 后重新 npm start。

4. Postman 测 CRUD（Task 3 / Task 4）

地址均为 http://localhost:3000，Body 选 raw → JSON：

全对说明 Task 3 + Task 4 完成。测完 Ctrl+C 停服务器。

Endpoints

MethodPathDescription
GET/Health check
GET/api/usersList all users
GET/api/users/user/:idGet one user by numeric id
GET/api/getrandomuserGet a random user (path from the lab wording)
GET/api/users/randomSame, textbook-style path
POST/api/users/newuserCreate user (id, email required)
PUT/api/users/modify/:idUpdate username, returns 200 + updated user
DELETE/user/delete/:idDelete user (also available at /api/users/delete/:id)

Route errors (400/404) return { "message": "..." }; errors passed to next(err) return { "error": { "message": "..." } } from the final handler. PUT returns 200 with the updated document; DELETE returns 204 No Content.
